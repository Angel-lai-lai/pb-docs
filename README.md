# pb-docs

Internal docs & prototypes hosted on GitHub Pages.

## Structure
```
pb-docs/
├── angel/      ← Angel's HTML files
├── brian/      ← Brian's HTML files
├── kaia/       ← Kaia's HTML files
└── salina/     ← Salina's HTML files
```

## How to upload
1. Open this repo on github.com
2. Click your folder
3. **Add file → Upload files** → drag your HTML in
4. Scroll down → **Commit changes**

Your file is live at `https://petit-bazaar.github.io/pb-docs/<your-folder>/<filename>.html` in ~30 seconds.

## Phase
This is the **Phase 1 POC** — pure GitHub Pages, no token gate yet. See [host-html design doc](../host-html/index.html) for the full plan.
